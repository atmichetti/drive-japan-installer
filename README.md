# Drive Japan Installer

Download the latest Windows installer from the [Drive Japan download website](https://atmichetti.github.io/drive-japan-installer/).

The site always links to the newest `.exe` attached to the [latest GitHub release](https://github.com/atmichetti/drive-japan-installer/releases/latest). The installer includes a setup wizard, desktop shortcut, and Start Menu shortcut. Drive Japan is not code-signed, so Windows SmartScreen may show a warning; only continue if you trust the download source.

Drive Japan is a 3D free-driving game set in a Japanese-inspired city. The game supports keyboard/mouse and standard Xbox-style controllers.
